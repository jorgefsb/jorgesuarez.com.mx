> **Documentando el camino: Dos décadas de lecciones en la trinchera del emprendimiento tecnológico y el gaming global.**

Este es el repositorio oficial de la landing page de **Jorge Suárez**, un espacio diseñado para proyectar la intersección entre el liderazgo empresarial AAA, el escalado de estudios de videojuegos y la experimentación tecnológica con Inteligencia Artificial.

## 🧬 Visual & Tech DNA

La experiencia de usuario está diseñada bajo un enfoque **"High-End / AAA Experience"**, inspirada en los estándares de calidad de **Amber Studio**.

- **🎨 Estética**: Glassmorphism, tipografía `Outfit` & `Inter`, y una paleta de colores oscuro-premium con acentos en naranja Amber.
- **✨ VFX**: Simulación de fluidos WebGL personalizada ("Liquid Smoke") para una interactividad atmosférica que no compromete el rendimiento.
- **🛠️ Tech Stack**:
  - **Core**: HTML5 semántico & CSS3 (BEM-ish methodology).
  - **Motion**: WebGL + GSAP logic para revelaciones y scroll.
  - **Logic**: Vanilla Javascript para optimización máxima de carga.
  - **Workflow**: Desarrollado bajo la metodología **"Vibecoding"**, utilizando agentes de IA para iteraciones ultra-rápidas de diseño y código.

## 🗺️ Estructura del Proyecto

- `index.html`: Arquitectura de navegación y contenido narrativo (5W+1H).
- `styles.css`: Sistema de diseño basado en variables y utility classes personalizadas.
- `vfx/`: Repositorio de scripts visuales (WebGL Fluid Simulation v2).
- `brand-guidelines.md`: Manual de identidad y tono de voz del proyecto.
- `task.md`: Log de vida y seguimiento de milestones (Kaizen Workflow).
